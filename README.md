# Practicar temas

Herramienta para practicar la voz del coro: suenan todas las voces, el micrófono te dice si estás afinado, y hay una prueba para saber cuál es tu voz.

Abrila en https://negromontes.github.io/practicar-temas/ — funciona en teléfonos, tablets y computadoras, sin instalar nada. Los temas se guardan en cada dispositivo.
